## Behaviors & Interaction Model

- **Header:** Fixed at top. Has glassmorphism — translucent dark background with backdrop-blur over hero photo, becomes light cream/translucent on light sections. Logo color stays cream over dark hero, switches to orange branded color on light sections.
- **Floating chat bubble** (orange CO badge bottom-left) — site-wide, fixed position
- **Carousel sections (#7, #10, #14, #17):** horizontal scrolling sub-cards with prev/next round orange arrow buttons + dot pagination indicator
- **No Lenis/smooth scroll library detected** — native scrolling
- **Hero phone mockup:** static image overlay
- **Sub-cards "En savoir plus →":** hover/link state with arrow

## Build Strategy

Given complexity, sections will be implemented as Next.js components in `src/components/sections/`. The page assembles them top-to-bottom in `src/app/page.tsx`. Foundation (fonts + tokens + nav + footer) goes first. Then content sections built in groups.
